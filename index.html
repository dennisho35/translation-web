                🚀 接下來如何執行？（解除紅字 `未啟動` 與 `BLOCKED_OFFLINE` 的 3 個步驟）
              

              Windows 本機實戰指引
            

            

              

                
步驟 1：解壓縮並啟動本機 Runtime

                

                  因為瀏覽器基於安全限制無法自己啟動電腦背景程式，請先下載並解壓縮 voicelink_ai_local_first_complete.zip，雙擊執行裡面的 windows/setup_and_start_all.bat（或 start_windows_runtime.bat）。
                

              

              

                
步驟 2：啟動本機 Qwen2.5 翻譯引擎

                

                  在 Windows 終端機 (CMD / PowerShell) 執行：

                  ollama run qwen2.5:7b-instruct

                  完成後點擊本頁上方「🔄 檢測本機 AI 引擎」，頂部狀態燈號即會由紅轉綠 🟢！
                

              

              

                
步驟 3：下載或載入模型計算真實 SHA-256

                

                  當步驟 1 的 Runtime 啟動後，點擊下方模型卡的「⬇ 下載」即可透過 127.0.0.1:11435 執行 .tmp 斷點續傳；你也可以直接點擊每張卡片右下角「官方來源 ↗」下載後，按右上角「🔐 載入本機模型檔計算真實 SHA-256」。
                

              

            

          


          
          

            

              
🧪 原子下載 (`.tmp` → Final) + HTTP Range 斷點續傳 + WebCrypto 真實 SHA-256 實測器

              
點擊右側按鈕可在瀏覽器內針對真實二進位測試載荷執行 Range 分段下載、暫停/續傳與 SHA-256 比對。
